CueCueNote Privacy Policy / プライバシーポリシー / 隐私政策

Last updated: October 3, 2026

日本語

kazunoriri（以下「開発者」）は、CueCueNoteにおける情報の取扱いについて、以下のとおり定めます。

開発者によるデータ収集

開発者は、CueCueNoteからユーザーデータを収集しません。Analytics、Tracking、広告SDK、第三者SDKは使用していません。CueCueNoteから開発者のサーバーへユーザーデータを送信する機能はありません。App Store ConnectのApp Privacyでは「データの収集なし」と申告しています。

端末内のデータと音源

Notes、Project、再生設定などのアプリデータは、ユーザーの端末内に保存されます。読み込んだ音源の再生・分析も端末上で行います。CueCueNoteは、YouTube、Apple Music、SoundCloudなどの第三者配信サービスから音源を取得・ダウンロードしません。

KeychainとiCloud

Notesの保存にはAppleのKeychain標準機能を使用します。ユーザーがiCloud保存を利用する場合、CueCueNoteはAppleの標準OS機能を通じて、ユーザー自身のiCloudアカウント内の非公開領域にデータを保存します。開発者がこのデータを受け取ることはありません。iCloudの提供に伴うAppleによるデータ処理は、Appleのプライバシー条件に従います。

「AIに聞く」と共有機能

「AIに聞く」は、CueCueNoteの一般的な機能説明ファイルをiOS標準共有シートに渡します。このファイルにユーザーの音源、曲名、Note本文、Project名、再生履歴は含まれず、CueCueNoteが外部AIへ自動送信することもありません。ユーザーが共有シートから送信先を選び、自ら共有した場合は、その送信先のプライバシー条件が適用されます。

診断ログも端末内に保存されます。ユーザーがサポートのためにログを書き出して共有する場合、ログには技術的なイベント情報やファイル名が含まれることがあります。共有先はユーザーがiOS標準共有シートで選びます。開発者がログを自動受信することはありません。

お問い合わせ

本ポリシーに関するお問い合わせは kazunoriri@gmail.com までご連絡ください。

English

This policy explains how kazunoriri (the “Developer”) handles information in CueCueNote.

Data collection by the Developer

The Developer does not collect user data from CueCueNote. The app uses no analytics, tracking, advertising SDKs, or third-party SDKs. CueCueNote does not send user data to a Developer-operated server. App Store Connect App Privacy is declared as “Data Not Collected.”

On-device data and audio

App data such as Notes, Projects, and playback settings is stored on the user’s device. Imported audio is played and analyzed on the device. CueCueNote does not retrieve or download audio from third-party streaming services such as YouTube, Apple Music, or SoundCloud.

Keychain and iCloud

CueCueNote uses Apple’s standard Keychain functionality to store Notes. If the user enables iCloud storage, CueCueNote uses standard Apple OS functionality to store data in the user’s private iCloud account. The Developer does not receive this data. Apple’s processing in connection with iCloud is subject to Apple’s privacy terms.

“Ask AI” and sharing

“Ask AI” passes a file describing CueCueNote’s general features to the standard iOS share sheet. The file does not contain the user’s audio, track titles, Note text, Project names, or playback history, and CueCueNote does not automatically send it to an external AI service. If the user selects a destination and shares the file, the destination’s privacy terms apply.

Diagnostic logs are stored on the device. If the user exports and shares a log for support, it may contain technical event information and file names. The user selects the destination in the standard iOS share sheet. The Developer does not receive logs automatically.

Contact

For questions about this policy, contact kazunoriri@gmail.com.

简体中文

本政策说明 kazunoriri（以下简称“开发者”）如何处理 CueCueNote 中的信息。

开发者的数据收集

开发者不会通过 CueCueNote 收集用户数据。本应用不使用分析、跟踪、广告 SDK 或第三方 SDK。CueCueNote 不会将用户数据发送到开发者运营的服务器。App Store Connect 中的 App Privacy 申报为“未收集数据”。

设备本地数据和音频

Notes、Project 和播放设置等应用数据保存在用户设备上。导入的音频也在设备上播放和分析。CueCueNote 不会从 YouTube、Apple Music 或 SoundCloud 等第三方流媒体服务获取或下载音频。

Keychain 和 iCloud

CueCueNote 使用 Apple 标准 Keychain 功能保存 Notes。如果用户启用 iCloud 保存，CueCueNote 会通过 Apple 标准操作系统功能，将数据保存到用户本人 iCloud 账户的私人空间。开发者不会收到这些数据。Apple 对 iCloud 的相关处理受 Apple 隐私条款约束。

“询问 AI”与分享

“询问 AI”会将介绍 CueCueNote 通用功能的文件交给 iOS 标准分享表单。该文件不包含用户的音频、曲目名称、Note 内容、Project 名称或播放记录；CueCueNote 也不会自动将其发送给外部 AI 服务。如果用户在分享表单中自行选择接收方并分享，接收方的隐私条款将适用。

诊断日志保存在设备上。用户为获得支持而导出并分享日志时，日志可能包含技术事件信息和文件名。用户可在 iOS 标准分享表单中选择接收方。开发者不会自动收到日志。
